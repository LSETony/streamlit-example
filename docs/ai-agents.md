# ИИ-агенты

В разделе **ИИ-агенты** (владелец и администратор) зал подключает агентов двух типов:

* **Встроенный** — работает внутри core. на модели Claude. Его запускают заданием из кабинета («найди клиентов,
  у которых абонемент заканчивается на этой неделе, и предложи продление») или он сам выполняет задание каждое утро.
* **Внешний** — свой агент зала (Claude, ChatGPT, Cursor, n8n, Make, свой код) подключается по API-ключу:
  через MCP-сервер или REST API.

## Права и безопасность

* Агент действует **от имени сотрудника, который последним сохранил его настройки** (владелец или администратор),
  через те же проверки, что и в кабинете. Сделать больше этого сотрудника агент не может. Если сотрудника отключили
  или сделали ресепшеном, агент останавливается, пока его не сохранит другой владелец или администратор.
* Каждый инструмент включается отдельно, с одним из режимов:
  * **Выкл.** — агент инструмента не видит;
  * **С подтверждением** — действие попадает в очередь «Ждут подтверждения», выполняет его сотрудник кнопкой
    «Подтвердить» (от своего имени);
  * **Сам** — агент выполняет действие без вопросов.
  Чтение данных — только «Выкл.» или «Вкл.».
* Все действия агентов (выполненные, отклонённые, с ошибкой) видны в «Журнале действий агентов», изменения
  абонементов — ещё и в журнале изменений зала (с пометкой `_ai_agent`).
* Агент видит только свой зал, даже если у сотрудника их несколько. Клиентам без согласия на рассылки агент не пишет.
* API-ключ показывается один раз, в базе хранится только его хеш. Ключ отзывается в карточке агента.

## Инструменты

| Инструмент | Тип | Что делает |
|---|---|---|
| `find_clients` | чтение | поиск клиентов по имени, телефону, email |
| `risk_clients` | чтение | клиенты «В зоне риска», сначала самые срочные |
| `client_details` | чтение | карточка: абонементы, визиты, записи, контакты |
| `schedule` | чтение | ближайшие занятия со свободными местами |
| `gym_stats` | чтение | показатели зала за месяц |
| `log_contact` | действие | отметить контакт с клиентом |
| `send_push` | действие | push в приложение клиента (с согласием на рассылки) |
| `send_whatsapp` | действие | шаблон WhatsApp Business (нужен подключённый WhatsApp) |
| `book_class` / `cancel_booking` | действие | записать на занятие / отменить запись |
| `freeze_membership` | действие | заморозить абонемент |
| `add_client_note` | действие | заметка в карточке клиента |

## Настройка

1. Миграция `supabase/migrations/20261116000001_ai_agents.sql` (или `supabase/setup-cloud.sql` для новой базы).
2. Для встроенных агентов — переменная `ANTHROPIC_API_KEY` на сервере (Vercel → Settings → Environment Variables).
   Модель по умолчанию `claude-opus-5-5`, сменить можно переменной `AI_AGENT_MODEL`.
   Внешним агентам ключ Anthropic не нужен.
3. Запуск по расписанию — `web/vercel.json` вызывает `/api/agents/cron` каждый день в 05:00 UTC.
   Задайте `CRON_SECRET` в переменных Vercel: Vercel передаёт его в заголовке, без него запуск отклоняется.
   На своём сервере — любой планировщик: `curl -H "Authorization: Bearer $CRON_SECRET" https://<кабинет>/api/agents/cron`.

## Подключение внешнего агента

Создайте агента с типом «Внешний», включите нужные инструменты и нажмите «Создать ключ».

**MCP** (Streamable HTTP, без сессий) — адрес `https://<кабинет>/api/agents/mcp`, ключ в заголовке:

```json
{
  "mcpServers": {
    "core": {
      "type": "http",
      "url": "https://<кабинет>/api/agents/mcp",
      "headers": { "Authorization": "Bearer core_ak_…" }
    }
  }
}
```

**REST**:

```bash
# инструменты, доступные по ключу
curl https://<кабинет>/api/agents/v1/tools -H "Authorization: Bearer core_ak_…"

# вызов инструмента
curl -X POST https://<кабинет>/api/agents/v1/tools/risk_clients \
  -H "Authorization: Bearer core_ak_…" -H "Content-Type: application/json" \
  -d '{"arguments": {"limit": 10}, "reason": "утренний обзор"}'
```

Ответы: `200 {"status":"done","result":…}`; `202 {"status":"pending_approval","action_id":…}` — действие ждёт
сотрудника; `401` — неверный или отозванный ключ; `403` — инструмент не разрешён; `404`/`422` — ошибка с `code`
и `message`.

## Ограничения

* Сообщение WhatsApp — только одобренный шаблон зала, текст агент не меняет.
* Встроенный агент делает до 20 шагов за запуск; задание из кабинета выполняется до 5 минут.
* Тексты из базы (заметки, имена) агент получает как данные; системная инструкция запрещает ему исполнять их как
  команды, но действия, которые пишут клиентам, надёжнее оставлять «с подтверждением».
