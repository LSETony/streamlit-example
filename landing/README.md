# Сайт core. (лендинг)

Отдельный статический сайт, кабинет (`web/`) не затрагивает. Один файл `index.html` и папка `assets/`
(видео из зала, скриншоты кабинета на русском и английском).

- Язык: RU/EN, переключатель в шапке; при первом заходе язык выбирается по браузеру.
- Кнопки «Войти» и «Подключить зал» ведут в кабинет: адрес задан в `APP_URL` в конце `index.html`.

## Публикация на Vercel

Vercel → Add New → Project → этот репозиторий → Root Directory: `landing`, Framework Preset: Other → Deploy.
Сборка не нужна. Свой домен (например `core.ru`) добавляется в Settings → Domains этого проекта.

Локально: `cd landing && python3 -m http.server 4100` → http://localhost:4100
