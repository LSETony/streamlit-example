# Быки и коровы — программа для конкурса

Компьютер отгадывает четырёхзначное число из разных цифр (первая цифра не 0).
После каждой попытки пользователь вводит позиции быков (например `2,4`) и количество коров.

```
g++ -std=c++17 -O2 -o bulls_cows bulls_cows.cpp
./bulls_cows        # игра
./bulls_cows -f     # без случайного перемешивания, первый ход всегда 2135
./bulls_cows -z     # разрешить 0 первой цифрой
./bulls_cows -t     # сыграть со всеми 4536 числами и вывести статистику
```

## Алгоритм

1. **Кандидаты.** Программа хранит все числа, которые не противоречат ни одному
   ответу, и после каждого ответа вычёркивает несовместимые. Это полная версия
   «алфавита с вычёркиванием цифр»: учитываются и отсутствующие цифры, и
   зафиксированные быки, и все комбинации ответов.
2. **Первый ход — 2135**, дальше ходы выбираются адаптивно, без фиксированной серии.
3. **Выбор хода** среди всех 4536 чисел (не только среди кандидатов):
   * больше 600 кандидатов: ход с максимальной энтропией ответа, то есть такой,
     который разбивает кандидатов на самые мелкие и ровные группы;
   * от 21 до 600: 60 лучших по энтропии ходов доигрываются до конца, выбирается
     ход с наименьшим худшим случаем, а при равенстве — с наименьшей суммой ходов;
   * 20 и меньше: полный перебор (оптимальное дерево) с запоминанием.
4. **Защита от анализа кода.** При каждом запуске цифры 1–9 и позиции 2–4
   случайно переставляются. Сила игры от этого не меняется, но подобрать по
   исходнику «неудобное» для программы число нельзя.

## Сравнение (все 4536 чисел, подсчёт `-t`)

| Стратегия | Среднее | Худший случай |
|---|---|---|
| Фиксированная серия 2135, 4357, 6579, 8790, затем оптимальный добор | 5.39 | 7 |
| Минимакс (меньше всего кандидатов в худшем ответе), исходная Python-версия без лимита в 5 ходов | 4.65 | 7 |
| Максимум энтропии | 4.61 | 7 |
| **Эта программа** | **4.58** | **6** |

Распределение для этой программы: 1 ход — 1 число, 2 — 15, 3 — 277, 4 — 1734,
5 — 2093, 6 — 416. Любое число угадывается не позже 6-й попытки.

С ключом `-z` (0 может быть первой цифрой, 5040 чисел) в среднем 4.65 хода,
но 12 чисел требуют 7 попыток.

В исходной Python-версии стоял лимит `MAX_TURNS = 5`, из-за которого 509 чисел
(6–7 ходов) не отгадывались совсем. Кроме того, когда оставался один кандидат,
она писала «число найдено», не сделав этот ход. Здесь последний кандидат всегда
называется отдельной попыткой, как требуют правила.
